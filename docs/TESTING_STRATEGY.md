# Focused testing strategy

The source of truth is `.cline/skills/react-unit-testing/SKILL.md`. This document expands the philosophy for maintainers.

## Test selection and evidence

- Test an explicitly selected target; otherwise use Git to identify new/changed component and hook candidates.
- Read related imports that affect **observable behavior** (props, validators, hooks, providers, HTTP boundaries). Inspect importers when changed public behavior could affect them.
- Propose dynamic scenarios with a trigger/input, observable expectation, and source evidence. No unrelated test generation across the repository.

## Quick and Detailed

**Quick** prioritizes critical paths, uses narrow context, and verifies the selected test. **Detailed** broadens the investigation where valuable, explores legitimate negative/boundary/async branches, and may run related regressions or inspect existing coverage.

Neither mode enforces arbitrary counts, execution durations, coverage percentages, token quotas, or maximum repair loops. Security limits on helper output and per-command process execution are separate from these user-facing depth modes.

## Existing Jest/Vitest convention

Do not migrate a Jest-only project. Honor `jest.fn` versus `vi.fn`, CommonJS `require`, test environment setup, mock patterns, path aliases, and existing scripts. If neither runner is installed, explain the blocker instead of automatically installing a new framework.

## Test confidence

1. Check syntax and basic test structure (heuristic only).
2. Execute the selected test using the project's runner with approval.
3. Diagnose test implementation errors versus possible application bugs; never weaken assertions to turn red into green.
4. Where justified, run related regression tests. A passing full suite does not prove all paths are correct.
5. Report actual passed/failed/skipped counts and real coverage only when generated by the test runner.

A static dependency graph approximates imports; context/providers, runtime DI, and dynamic imports may need manual inspection.
